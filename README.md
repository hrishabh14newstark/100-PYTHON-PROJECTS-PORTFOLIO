# 100 Python Projects: From Beginner to Advanced

Welcome to this comprehensive list of 100 Python projects, organized from foundational scripts to complex systems.

## 🟢 Beginner: Core Mechanics & Scripting (1–25)
These projects focus on mastering Python's basic syntax, logic, and standard libraries without needing external databases or complex frameworks.

1. **Number Guesser:** A command-line game that provides "higher" or "lower" hints.
2. **Mad Libs Generator:** An exercise in string formatting and user input.
3. **Password Generator:** Generate secure, random passwords using the `secrets` module.
4. **Dice Simulator:** Randomize and print the outcome of rolling multiple dice.
5. **Hangman:** A terminal-based word guessing game using string manipulation and loops.
6. **Tic-Tac-Toe:** Build a 2-player game using a 2D array and basic game logic.
7. **To-Do List (CLI):** Manage tasks using basic text file read/write operations.
8. **Unit Converter:** A dictionary-based tool to convert lengths, weights, or temperatures.
9. **Basic Calculator:** Implement functions for math operations.
10. **Countdown Timer:** A terminal timer utilizing the `time` module.
11. **Alarm Clock:** Schedule a sound or print statement at a specific time.
12. **Word Counter:** Parse text files to count frequency of words using dictionaries.
13. **Palindrome Checker:** A script to reverse strings and check for symmetry.
14. **Fibonacci Generator:** Generate sequences using either recursion or iteration.
15. **BMI Calculator:** Simple math and conditional logic based on user weight and height.
16. **Magic 8-Ball:** Return randomized responses to user questions.
17. **File Renamer:** Use the `os` module to batch-rename files in a directory.
18. **Directory Scanner:** Traverse folders to list file types and calculate sizes.
19. **Currency Converter:** Make simple HTTP requests to a free exchange rate API.
20. **Desktop Notifier:** Push OS-level alerts using the `plyer` library.
21. **QR Code Generator:** Convert URLs or text into images using the `qrcode` library.
22. **Text-to-Speech Script:** Convert strings to audio using `pyttsx3`.
23. **Wikipedia Fetcher:** Retrieve and summarize random articles using the Wikipedia API.
24. **Rock, Paper, Scissors:** A classic conditional game against a computer opponent.
25. **Caesar Cipher:** Create a simple text encryption and decryption tool.

## 🟡 Intermediate: Web, Data & Automation (26–50)
These projects introduce external libraries, graphical interfaces, web scraping, and database management.

26. **Weather App:** Fetch API data and display it in a Tkinter GUI.
27. **Expense Tracker:** Implement CRUD (Create, Read, Update, Delete) operations with SQLite.
28. **Personal Blog:** Build a basic routing app using Flask or Django.
29. **URL Shortener:** A web app that hashes long links into short redirects.
30. **Amazon Price Scraper:** Use `BeautifulSoup` to track product prices over time.
31. **Automated Emailer:** Send daily reports or alerts using `smtplib`.
32. **Bulk Image Resizer:** Batch process folders of images using the `Pillow` library.
33. **Pomodoro Timer:** A GUI productivity app with work/rest intervals.
34. **Reddit Bot:** Use PRAW to automatically fetch posts or reply to specific keywords.
35. **Discord Bot:** Handle chat commands and moderation using `discord.py`.
36. **PDF Merger:** Automate the compilation of multiple PDFs using `PyPDF2`.
37. **CSV to JSON Converter:** A data formatting script for data ingestion.
38. **System Resource Monitor:** A dashboard displaying CPU and RAM usage using `psutil`.
39. **Typing Speed Tester:** Measure words-per-minute via a terminal or GUI interface.
40. **Password Manager:** Secure local storage using the `cryptography` library.
41. **Markdown to HTML Converter:** A script to parse and format text structures.
42. **Music Player:** A basic audio GUI built with the `pygame` mixer.
43. **Flashcard App:** Implement spaced repetition logic for studying.
44. **Web Crawler:** Recursively index the links and text of a small static website.
45. **API Rate Limiter:** Build Python decorators to limit function calls over time.
46. **Stock Price Dashboard:** Pull and graph financial data from public APIs.
47. **Automated File Sorter:** Organize a cluttered Downloads folder by file extension.
48. **Habit Tracker API:** Build RESTful endpoints using FastAPI.
49. **Sudoku Solver:** Implement a backtracking algorithm to solve puzzles.
50. **Maze Generator:** Visualize depth-first search algorithms.

## 🟠 Hardware, Electronics & IoT (51–75)
Python is a powerhouse for embedded systems, serial communication, and data logging. These projects bridge the gap between software and the physical world.

51. **Arduino Serial Monitor:** Read, log, and graph data from a microcontroller using `pyserial`.
52. **Battery Charge/Discharge Logger:** Parse telemetry data (voltage/temperature) from a Battery Management System (BMS).
53. **Raspberry Pi Weather Station:** Interface with physical I2C/SPI sensors (like BME280).
54. **MicroPython LED Controller:** Write scripts to blink LEDs and generate PWM signals on an ESP32.
55. **Oscilloscope Waveform Plotter:** Pull waveform data via PyVISA and graph it with Matplotlib.
56. **IoT Battery Capacity Estimator:** Calculate total mAh over time from raw current logs.
57. **Automated Multimeter Reader:** Parse SCPI commands from bench hardware.
58. **Relay Switch Controller:** Build home automation logic using Raspberry Pi GPIO pins.
59. **Sensor Data Dashboard:** Real-time plotting of analog sensor data using Streamlit.
60. **Motor Control API:** Send step and direction commands to a stepper motor driver.
61. **Thermal Camera Matrix Fetcher:** Read arrays from I2C thermal sensors (like the MLX90640).
62. **Logic Analyzer Parser:** Script to parse CSV exports from a logic analyzer to find signal anomalies.
63. **RFID Attendance System:** Interface an RC522 reader with a local SQLite database.
64. **Li-ion Voltage Alerter:** A script that sends a webhook if a monitored cell drops below 3.0V.
65. **MQTT Message Broker Client:** Send and receive IoT telemetry data across a network.
66. **Bluetooth LE Device Scanner:** Find and log nearby BLE beacons using `bleak`.
67. **I2C EEPROM Flasher:** A script to read and write configuration data to external memory chips.
68. **CAN Bus Sniffer:** Read and decode automotive or industrial network frames using `python-can`.
69. **PCB Component Tracker:** A database application for managing an electronics lab's inventory.
70. **Automated Test Equipment (ATE):** Sequence a suite of pass/fail tests for circuit boards.
71. **Solar Efficiency Tracker:** Correlate ambient lux sensor data with panel voltage output.
72. **PID Controller Simulation:** Visualize tuning parameters (Proportional, Integral, Derivative) for a heating element.
73. **Web-based Oscilloscope:** Stream serial analog data to a web browser via WebSockets.
74. **Capacitance Meter Script:** Calculate RC time constants from raw Data Acquisition (DAQ) inputs.
75. **Hardware Watchdog Daemon:** Ping network devices and trigger relays to power-cycle them if they hang.
